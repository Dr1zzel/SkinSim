# Questions

This toolbox exists to answer the questions below. The list is the stopping criterion: the toolbox is finished when it can answer these, not when it feels complete.

1. How far along a vessel does each contrast mechanism keep usable contrast, as a function of blood velocity and vessel orientation?
2. Which mechanism wins against each background tissue — dermis at 0–2 mm, subcutaneous fat at 2–10 mm — and can one protocol serve both?
3. Which mechanism gives the most contrast per unit scan time, and where is the boundary between them?
4. Can a prepared sequence beat an unprepared short-TE acquisition once scan time is counted?
5. Does slab orientation relative to the skin surface change the answer, including the cost of covering the same area with more slabs?
6. Which tissue parameter dominates the uncertainty, and therefore what should be measured first?
